SGEPR - pantalla demostrativa para H3-T4
========================================

Archivos:
- index.html: estructura de la pantalla
- styles.css: estilos adaptables a escritorio y móvil
- script.js: validación del formulario, alta local y filtro de búsqueda


Alcance:
- Prototipo front-end. No utiliza base de datos ni servidor.
- Los dos registros iniciales son ficticios.
- Los datos agregados solo viven en memoria mientras la página permanece abierta.
- No ingresar datos personales, judiciales ni clínicos reales.
- No realiza diagnóstico ni predicción clínica.
